# 최서진 돌보기 — 2인 온라인 결투 버전

서영과 서인이 **각자 폰**으로 같은 방에 들어가, 미니게임(거품내기 · 지니 잡기)으로 돌봄 담당자를 정하는 웹앱입니다.
멀티플레이는 p5.party(공개 데모 서버)로 연결합니다.

---

## 1. 파일 구조

```
seojin-care/
├─ index.html          화면 뼈대 (설정 / 메인 / 결투 화면)
├─ style.css           모양 — 맨 위 :root 에 색·크기 변수
├─ assets/
│   └─ seojin-wet.png  ← 젖은 서진이 사진을 여기에 넣어 주세요 (아래 3번)
└─ js/
   ├─ config.js        ★ 바꾸고 싶은 값은 거의 여기 (이름, 색, 시간, 서버, 돌봄 목록)
   ├─ icons.js         발바닥 · 결투(칼) 아이콘 (SVG)
   ├─ storage.js       돌봄 기록 (p5.party로 두 폰 공유 + 이 폰에 복사본)
   ├─ sensors.js       흔들기 센서 + iPhone 권한 요청
   ├─ camera.js        카메라 + ml5 bodyPose(몸 동작 인식)
   ├─ network.js       p5.party 연결, 방, 결투 진행 규칙
   ├─ app.js           화면 그리기 + 버튼 동작
   └─ games/
      ├─ registry.js   미니게임 목록 (룰렛에 나오는 4종)
      ├─ bubble.js     거품내기 게임 (p5.js)
      └─ jini.js       지니 잡기 게임 (p5.js + ml5 카메라)
```

## 2. 실행하기

**컴퓨터에서 확인:** VS Code에서 `index.html` → Live Server.
PC에는 흔들기 센서가 없어서 자동으로 **화면 문지르기**로 바뀝니다.
브라우저 창 두 개(하나는 시크릿 창)를 띄우면 혼자서도 두 사람 역할을 테스트할 수 있어요.

**폰에서 실제 결투:** GitHub Pages에 올린 `https://` 주소로 들어가야 합니다.
iPhone은 `http://` 주소(Live Server를 폰에서 여는 경우)에서는 흔들기 센서를 아예 막아요.

### GitHub Pages 배포
1. GitHub에 새 저장소 → 이 폴더 안의 파일을 전부 올리기
2. Settings → Pages → Branch: `main` / `/ (root)` → Save
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 접속

## 3. 서진이 사진 넣기

Figma 거품내기 화면의 **'젖은 개 1'** 레이어를 선택 → 오른쪽 아래 Export → PNG(2x) →
파일 이름을 `seojin-wet.png`로 바꿔 `assets/` 폴더에 넣으면 끝.
사진이 없으면 코드가 간단한 강아지 그림으로 대신 그려요.

## 4. 사용 순서

1. 처음 열면 **방 코드** 입력 → 둘이 **같은 코드**를 넣어야 같은 방 (랜덤 버튼으로 만들어서 카톡으로 공유)
2. **나는 누구?** → 서영 / 서인 선택 (상대가 이미 고른 이름은 눌리지 않음). 다음부터는 자동 입장
3. 메인에서 할 일 카드를 누르면 펼쳐짐 → `서영` / `서인`(완료 체크) 또는 `결투`
4. 결투 → 두 폰 모두 룰렛 → 게임 안내 → 둘 다 **준비 완료**를 누르면 3, 2, 1
5. 20초 동안 흔들기 → 두 폰에 같은 결과 → 진 사람이 그 일 담당 (카드 왼쪽에 담당자 색 띠)

아래 고정 띠(방 코드 · 초록 점)를 누르면 접속 상태 확인, 혼자 연습, 방/사람 바꾸기를 할 수 있어요.

## 5. 이렇게 동작해요 (멀티플레이 설계)

- **반장(호스트) 한 명만 결투 상태를 씁니다.** 두 폰이 같은 데이터를 동시에 쓰면 한쪽이 사라지기 때문.
  각 폰은 자기 메모(역할, 준비, 점수)만 쓰고, 반장이 그걸 보고 다음 단계로 넘깁니다.
  반장 폰이 나가면 남은 폰이 자동으로 반장이 되어 이어 갑니다.
- **흔들기 입력은 각자 폰에서 처리**하고, 점수만 0.3초마다 공유합니다. 게임 중 상대 점수도 실시간으로 보여요.
- **시간은 각 폰 시계로 잽니다.** 폰마다 시계가 몇 초씩 다를 수 있어서 '몇 시 몇 분에 끝'이 아니라
  '게임 화면을 본 순간부터 20초'로 재고, 둘 다 끝났다고 알리면 반장이 판정합니다.

| 상황 | 처리 |
|---|---|
| 서버 연결 실패 | 10초 안에 안 되면 안내 + 다시 시도 버튼. 돌봄 체크는 연결 없이도 계속 사용 가능 |
| 게임 중 연결 불안정 | 화면 위 빨간 띠로 알림 |
| 상대가 나감 | 12초 기다려 줌(새로고침일 수 있으니) → 그래도 없으면 결투 취소 + 양쪽 알림 |
| 두 사람이 동시에 결투 신청 | 반장이 먼저 온 요청 하나만 받음 → 두 폰 모두 같은 일로 진행 |
| 진행 중 또 결투 신청 | "이미 결투가 진행 중이에요" |
| 새로고침 | 같은 폰이라는 걸 기기 번호로 알아보고 이름·준비·점수·남은 시간을 이어 감. 예전 탭은 '유령'으로 무시 |
| 결과 화면에서 새로고침 / 늦게 접속 | 지난 결과를 받아서 기록에 한 번만 반영 |
| 다른 폰이 같은 이름을 고름 | 경고 띠 + 이름 바꾸기 |
| 무승부 | 담당자 저장 안 함 → '다시 한 판' |
| iPhone 센서 권한 | '준비 완료'를 누르는 순간 요청. 새로고침 후엔 "화면을 눌러 센서 다시 켜기" |
| 센서 없음 / 거부 | 화면 문지르기로 대체 (config.js `ALLOW_TOUCH_FALLBACK`로 끌 수 있음) |

## 6. 자주 바꿀 값 (js/config.js)

- 게임 시간: `PLAY_MS: 20000` (20초. Figma처럼 30초로 하려면 30000)
- 거품이 잘 생기는 정도: `BUBBLE.ENERGY_PER_BUBBLE` (작을수록 잘 생김), `SHAKE_THRESHOLD`
- 사람 이름/색: `PLAYERS`
- 기본 돌봄 목록과 주기: `DEFAULT_TASKS`

## 7. 새 미니게임 추가

1. `js/games/bubble.js`를 복사해 `js/games/새게임.js` 작성 (`create()`가 `start / stop / score / setScore / destroy`를 돌려주면 됨)
2. `index.html`에 `<script src="js/games/새게임.js"></script>` 한 줄
3. `js/games/registry.js`에서 그 게임을 `playable: true`, `module: () => 새게임`

룰렛은 모든 게임을 보여 주지만, **실제로는 `playable: true`인 게임만 뽑힙니다.** 지금은 거품내기 · 지니 잡기 두 개.
registry.js의 `unit`(개/번), `countdownSub`, `judging`, `tieText` 같은 글자도 게임마다 바꿀 수 있어요.

## 7-1. 지니 잡기 (카메라 게임)

- **조작:** 폰을 세워 두고 상체가 다 보이게 한 걸음 뒤로 → 팔을 쫙 벌리면 두 손 사이에 노란 점선 + 조준점 →
  조준점을 지니에 맞춘 채 두 손을 모으면 포획. 잡을수록 지니가 빨라져요.
- **원리:** ml5 `bodyPose`(MoveNet)가 손목·어깨 위치를 알려 줌. 손목 사이 거리를 **어깨너비의 몇 배**로 비교해서
  카메라와 가깝든 멀든 똑같이 '벌림/모음'을 판단해요. 두 손이 만난 지점에 지니가 있으면 성공.
  (티처블 머신 분류 모델은 '모았다'는 알아도 '어디서'는 몰라서 이 게임엔 안 맞아요.)
- **지니 사진:** `assets/jini.png`(배경 투명 PNG 추천)를 넣으면 그림 대신 사진이 뛰어다녀요.
- **난이도 조절 (config.js `JINI`):** `CATCH_RADIUS`(↑ 쉬움), `OPEN_RATIO`(↓ 덜 벌려도 됨), `CLOSE_RATIO`(↑ 덜 붙여도 됨),
  `SPEED` · `SPEED_UP` · `MAX_SPEED`
- **카메라 권한:** '준비 완료'를 누를 때 물어봐요. https(GitHub Pages)나 Live Server(localhost)에서만 켜져요.
  거부·카메라 없음 → 지니를 손가락으로 눌러서 잡기 (`ALLOW_TOUCH_FALLBACK`)
- ml5는 무거워서 지니 잡기 안내 화면이 뜰 때만 불러와요. 처음엔 준비 버튼 후 몇 초 걸릴 수 있어요.
- 결투 화면에서 나가면 카메라가 자동으로 꺼져요.

## 8. 알아 둘 한계

- **공개 데모 서버**는 프로토타입용입니다. 서버가 재시작되면 방이 비고, 같은 앱 이름 + 방 코드를 아는 사람은 누구나 들어올 수 있어요.
  `APP_NAME`은 고유하게 두고, 방 코드는 남이 추측하기 어렵게 정하세요.
- **돌봄 체크 기록은 같은 방의 두 폰이 공유**합니다 (완료 체크·취소, 할 일 추가·삭제, 결투 담당자).
  각 폰에도 복사본이 남아서, 데모 서버가 재시작돼 방이 비면 먼저 들어온 폰의 복사본으로 다시 채워져요.
  방에 연결되지 않은 상태에서 체크한 것은 다음에 연결될 때 보내져요.
- 개발용: 주소 뒤에 `?server=ws://localhost:6020`을 붙이면 직접 띄운 서버로 테스트할 수 있어요.
